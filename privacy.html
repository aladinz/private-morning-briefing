Privacy Policy

Private Morning Briefing is a personal application used by one person (its developer) with that person's own email account.

Data accessed: email messages, via Google's Gmail API, using a read-only permission (gmail.readonly). The app cannot send, modify, or delete email.

How data is used: all processing happens locally on the user's own computer, including summarisation by a locally running language model. No email content is transmitted to any third party, sold, or used for advertising.

Storage: generated summaries are stored only on the user's own computer and are automatically deleted after 7 days.

Revoking access: access can be revoked at any time at myaccount.google.com/connections, which immediately ends the app's ability to read email.

Contact: via the GitHub profile that owns this site.
